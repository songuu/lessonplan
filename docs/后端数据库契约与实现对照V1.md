# 数据库事实源

唯一DDL入口Alembic；`0001`创建核心表，`0002`增加个人库分块/缩略图与按小时样本统计，`0003`增加独立知识库、引用快照、执行租约与运行断点。当前head以`uv run alembic heads`为准。应用/Worker启动均不调用create_all；隔离测试fixture允许建临时表。

| ORM | 物理表 | 事实 |

| TokenRevocation | auth_token_revocations | 即时注销黑名单 |

| Run/Event | ai_generation_runs/ai_generation_events | 运行唯一状态、epoch/owner/租约/恢复次数及单调事件 |

本仓库从零实现，不伪造原文不存在的历史迁移。与旧参考架构的物理投影差异明确如下：User中合并档案与偏好JSON；反思/模块润色共用表但由kind和独立API/保存目标隔离；个人教案风格分块以PersonalLesson.chunks JSON持久化，知识资料则使用独立知识表；没有知识图谱、长期画像或教师质量评分表。数据库保留明确的领域边界与所有权检查。

所有日期用UTCDateTime，SQLite回读也保持UTC。JSON字段完整重新赋值，避免嵌套修改漏持久化。模块版本draft/module/version_no唯一；Event run/sequence唯一；partial unique分别约束活跃前台Run与唯一终态Event。

Issue样本按user/workflow/hour的sample_key唯一，用数据库ON CONFLICT原子累加sample_count、success/failure/cancelled/degraded/slow_count、duration_ms_sum与observation_count。问题事实与样本分母分开；fallback保留问题事实而运行仍可success_with_warnings。不得用问题行数除以所有样本替代同sample_space统计。

迁移回滚会移除新增字段，生产执行前必须备份并评估数据损失。仓库测试仅对显式独立数据库升级/降级；未执行生产迁移。
