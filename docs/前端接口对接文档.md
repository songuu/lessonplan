# 教师端 HTTP / SSE 契约

实现入口为 `app/api/auth.py`、`catalog.py`、`lessons.py`、`knowledge.py`；完整字段以运行中的 `/openapi.json` 为准。业务前缀统一 `/api/v1`。独立知识库接口见[知识接口](知识检索与断点恢复.md#知识接口)。

成功 `{data: ...}`；失败 `{error:{code,message},request_id}`。401 重新登录，403 权限不足，404 隐藏他人资源，409 版本/幂等/状态冲突，422 输入或质量失败。Bearer JWT 放 Authorization，不能放 URL。注销立即撤销token。X-Request-ID 回传关联ID。

| 方法 | 资源 | 说明 |
|---|---|---|
| POST | `/auth/register`, `/auth/login`, `/auth/logout` | 注册登录返回 access_token/user；注销撤销当前token |
| GET/PATCH | `/me` | 档案，不接受role/tenant自我提升 |
| GET | `/profile-options`, `/lesson-dictionaries` | 学段/年级/学科/课型/模块 |
| GET/PUT | `/me/lesson-module-config` | `{modules:[...]}`；只影响后续创建 |
| GET | `/lesson-drafts?q=&status=&limit=&offset=` | 自己的未删除历史 |
| POST | `/lesson-drafts/generations/one-click`, `/interactive` | 创建草稿并启动首个Run |
| GET/DELETE | `/lesson-drafts/{id}` | 详情 / 软删除并取消活跃Run |
| POST | `/lesson-drafts/{id}/generations/one-click` | 重试，保留旧版本 |
| POST | `/lesson-drafts/{id}/interactive/step` | module_id、stage=outline/activities（教学过程） |
| POST | `.../interactive/confirm` | module_id+版本锁，可带outline |
| POST | `.../interactive/finalize` | 全部启用模块完成并确认后收口 |
| PATCH | `/lesson-drafts/{id}/modules/{mid}` | 保存新committed版本 |
| GET/POST | `.../modules/{mid}/versions`, `.../restore` | 版本历史 / version_id+版本锁恢复为新版本 |
| GET | `/generation-runs/{id}`, `/{id}/events` | 权威状态 / Bearer SSE |
| POST | `/generation-runs/{id}/cancel` | 幂等取消，禁止晚到结果提交 |
| POST | `/module-polish-sessions` | draft_id/module_id/scope/选区范围 |
| GET/POST | `/module-polish-sessions/{id}`, `/{id}/messages` | 候选与历史 / instruction+working_content→run_id |
| POST | `/lesson-drafts/{id}/preview`, `.../exports` | 快照 / format=docx/pdf→id/run_id |
| GET | `/lesson-exports/{id}`, `/{id}/download` | success后权限下载 |
| GET/PUT | `/lesson-drafts/{id}/post-lesson-reflection` | content/expected_version；独立版本 |
| POST | `.../post-lesson-reflection/polish` | instruction/working_content→候选Run |
| GET/POST | `/personal-lessons` | 列表 / multipart file上传 |
| DELETE/GET | `/personal-lessons/{id}`, `/{id}/download` | 删除 / 原文件下载 |
| POST | `/analytics/events` | event_name+属性白名单，不接受正文/Prompt |

创建输入：`request_id,topic,school_stage,grade,subject,lesson_type,total_duration_min,requirements?,modules?,knowledge_base_ids?`。知识库省略/null为当前教师全部知识库，[]为停用，显式列表最多50个。后端冻结选中知识库和相关片段至草稿。正式值为字典value（兼容中文label）。配置含module_type/display_name/enabled/module_summary，后端冻结稳定module_id和顺序。返回 `{draft_id,run_id}`。Idempotency-Key同键同参复用，同键异参/跨workflow拒绝。

详情modules中含配置、current_version_id、teacher_view_content、canonical_content、state。保存/恢复/确认要求 `expected_content_version`、`expected_current_module_version_id`、`expected_module_config_version_id`，任一变化409。

大纲：`[{stage_id,title,objective,duration_min}]`。确认只设置outline_confirmed，不代表完整教学过程已确认。activities严格使用确认大纲，之后单独确认；重生成outline清除旧确认。

SSE格式为 `id: sequence / event: type / data: {run_id,sequence,...payload}`。按序号去重，Last-Event-ID或after断点重放。仅content_delta.delta是正文；replace_previous=true替换模块，否则追加；临时正文不是正式版本。

事件：run_started、style_context_resolved、structured_step_started、message_started、module_progress、module_started、stage_started、content_delta、stage_done、module_done、polish_ready、structured_step_ready、draft_ready、interrupted、run_completed、run_failed、run_cancelled、heartbeat。蓝图与降级信息通过module_progress.phase承载。

一键和结构化使用相同正文事件。`module_started.module_id`关联冻结配置中的名称/顺序，`display_name/module_index/module_count`为可选提示；`stage_started`包含当前环节及可选`stage_index/stage_count`。实时进度按当前Run事件更新，不能等待最终草稿状态才显示。两种模式的目录仅显示模块名称与图标，名称下方不显示状态文字；当前模块/环节进度仍在顶部和正文区显示。大纲JSON按完整环节转成可读`content_delta`，不直接显示JSON；JSON兜底按完整模块发布增量。

`module_done.is_temporary=true`只表示本轮模块初稿已流完，仍需质量检查和正式提交。`module_progress.phase=generation_attempt_reset`按 `scope=all/module` 清除废弃临时正文，module范围只清指定模块；保留当前质量重试次数。`quality_retry_started`携带 `attempt/max_attempts/module_id`。模块内Provider重试用`content_delta.replace_previous=true`替换，课堂活动保留已完成环节。恢复可收到 `worker_recovering/checkpoint_restored`；只有完整模块checkpoint计为模块完成，单活动恢复不计整个模块完成。终态后读取正式版本成功再退出临时视图，读取失败后的手动重试也必须完成接续。

run_completed/run_failed/run_cancelled唯一终态。heartbeat不落库，数据库Event为事实源。断线携带Last-Event-ID并查询GET Run；失败保留临时正文。润色候选明确采用后再PATCH保存；选区只替换指定工作副本范围。
